# public

Statyczne zasoby kopiowane do wyniku builda: `brand/` i favicon to identyfikacja, `maps/` to styl i kafelki historyczne, `fonts/` zawiera licencje fontów, a `robots.txt` blokuje indeksowanie obecnej wersji. Ten README jest również kopiowany przez obecną konfigurację zasobów; nie umieszczamy tu danych prywatnych.

search-index.json i sitemap.xml są generowane z wybranego snapshotu i ignorowane przez Git. Nie stanowią wersjonowanej kopii rzeczywistego katalogu.

`icons/places/` zawiera dziewięć lokalnych ikon Lucide 0.468.0 dla głównych tagów miejsc. Plik `LICENSE.txt` zachowuje licencję ISC i informację o częściach Feather (MIT). Zmieniono kolor obrysu na biały oraz szerokość na 2,6; frontend wyświetla ikony w rozmiarze 22 px. Bez zewnętrznego CDN i bez nowych zależności runtime.
