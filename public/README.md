# public

Statyczne zasoby kopiowane do wyniku builda: `brand/` i favicon to identyfikacja (PNG 192 × 192 dla wyszukiwarek, wygenerowany z SVG), `maps/` to styl i kafelki historyczne, `fonts/` zawiera licencje fontów, a `robots.txt` blokuje indeksowanie dev (wariant produkcyjny ma odrębny plik). Ten README jest również kopiowany przez obecną konfigurację zasobów; nie umieszczamy tu danych prywatnych.

Mapa witryny jest generowana dynamicznie przez backend.

`icons/places/` zawiera dziewięć lokalnych ikon Lucide 0.468.0 dla głównych tagów miejsc. Plik `LICENSE.txt` zachowuje licencję ISC i informację o częściach Feather (MIT). Zmieniono kolor obrysu na biały oraz szerokość na 2,6; frontend wyświetla ikony w rozmiarze 22 px. Bez zewnętrznego CDN i bez nowych zależności runtime.

`googleb704511028ba7adb.html` to publiczny plik weryfikacyjny Search Console; musi pozostać dostępny po weryfikacji własności.
