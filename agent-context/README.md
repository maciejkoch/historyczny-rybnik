# Materiały pomocnicze agenta

Notatki, pamięć robocza, wyniki sprawdzeń i skrypty służące wyłącznie agentowi.

- [reference/](reference/README.md) — zachowane materiały przeniesione z dawnego `docs/`: plany, źródła i licencje, szczegóły infrastruktury, uzasadnienia decyzji oraz zapisy odbiorów.
- Obowiązujący opis funkcji jest w głównym README, stan techniczny w TECHNICAL, a praktyki w CONTRIBUTING. Materiały planistyczne i historyczne nie zastępują tych dokumentów.
- Nie zapisujemy sekretów. Narzędzia budowania i utrzymania aplikacji należą do `scripts/`.
