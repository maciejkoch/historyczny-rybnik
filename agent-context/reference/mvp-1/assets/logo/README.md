# Logo — Historyczny Rybnik

Wybrany przez właściciela kierunek: **03 · Ryba na mapie**, dolny lewy wariant na planszy.

![Propozycje logo](propozycje-logo.png)

Plik PNG jest oryginalną planszą koncepcyjną wygenerowaną narzędziem imagegen, a nie gotowym logo produkcyjnym. Pozostaje przygotowanie osobnego znaku SVG, wariantu z nazwą, wersji jednokolorowej oraz uproszczonej favicony.

Założenia wybranego kierunku: prosta sylwetka ryby połączona z układem ulic i punktem lokalizacji, ciemna zieleń `#245947`, uzupełniająca zieleń szałwiowa, nazwa „Historyczny Rybnik” krojem Lora. Ten kierunek zastępuje wcześniejszy monogram HR.
