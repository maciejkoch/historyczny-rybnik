# Kreator miejsc — materiały projektowe

> Katalog odtworzono 25 listopada 2026 po omyłkowym usunięciu. Wymagania i architekturę odzyskano z zapisu sesji, a makiety z zachowanych plików wizualizacji. Kod implementacji został wycofany.

Plan funkcji, nie opis aktualnie dostępnej aplikacji. Wymagania są punktem odniesienia, a makiety służą omówieniu układu i zachowania; zawierają przykładowe dane i symulowane akcje, nie zapisują zmian ani nie korzystają z AI.

- [Wstępna architektura](architektura-wstepna.md) — ustalenia techniczne, stan Firebase, próby modelu i otwarte kwestie.
- [Wymagania funkcjonalne](wymagania.md) — zakres MVP, scenariusze i kryteria odbioru.
- [Podział prac](podzial-zadan.md) — kolejność, zakres i kryteria odbioru dziesięciu zadań.
- [Projekt edytora](mocki/projekt-edytora.html) — nowszy podgląd desktopowego edytora z pełnym modelem miejsca.
- [Układ roboczy](mocki/uklad-roboczy.html) — wcześniejszy szkic listy i edytora; zawiera nieaktualny przycisk ręcznego zaznaczania wycinka. Uzgodnione wymagania przewidują zaznaczanie przez AI.

Pliki HTML można otworzyć w przeglądarce. Rozbieżności pomiędzy makietami a wymaganiami rozstrzygają wymagania; szczegółowy projekt architektury i infrastruktury wymaga dalszego opracowania.
